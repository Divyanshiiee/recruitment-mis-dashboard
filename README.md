# Recruitment Pipeline & HR MIS Dashboard

## Project Overview

This project is an Excel-based HR Recruitment MIS Dashboard developed to analyze and monitor recruitment pipeline activity and hiring outcomes.

The dashboard provides a consolidated view of candidate volume, recruitment status, selection outcomes, recruitment sources, recruiter performance, positions, locations, and monthly recruitment trends.

The project uses a synthetic recruitment dataset created for learning and portfolio purposes.

---

## Project Objectives

The main objectives of this project were to:

- Analyze the recruitment candidate pipeline
- Track candidates across different recruitment statuses
- Evaluate recruitment sources and their selection outcomes
- Analyze recruiter-level performance
- Compare recruitment activity across positions and locations
- Monitor monthly recruitment trends
- Create KPIs for recruitment monitoring
- Build an interactive HR MIS dashboard using Excel

---

## Dataset

The dataset contains fictional recruitment records covering the following information:

- Candidate ID and Candidate Name
- Application Date
- Position
- Department
- Location
- Recruitment Source
- Recruiter
- Screening Status
- Interview Stage and Status
- Final Status
- Offer Date
- Joining Status and Joining Date
- Recruitment duration metrics

The dataset contains **750 candidate records**.

> Note: The dataset is synthetic and does not contain real candidate information.

---

## Key Insights

Some of the key findings from the analysis include:

- A total of **750 candidates** entered the recruitment pipeline.
- **80 candidates were selected**, resulting in an overall selection rate of **10.67%**.
- **540 candidates were rejected**, while **130 candidates remained in progress**.
- Job Portals achieved the highest selection rate among the analyzed recruitment sources.
- LinkedIn generated the highest candidate volume, while Employee Referrals also showed strong selection performance.
- April recorded the highest number of selections, while July recorded the highest candidate volume.
- Business Analyst recorded the highest selection count among the analyzed positions.
